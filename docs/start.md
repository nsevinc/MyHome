# MyHome · Hızlı başlangıç / Quick start

<a id="web"></a>
## Web

**TR** · Yayımlanmış deponun ana sayfasında **Tarayıcıda aç** bağlantısını kullan. **Oda çiz** veya **Proje → Yerel projeler → Yeni boş oda** ile başla. Katalogdan bir gardırop ekle. Dolabı seçip LED konumu, malzemesi ve rengini ayarla. **3B görünüm → PNG indir** 1920 × 1080 görüntüyü indirir ve galeriye ekler. **Proje → Proje renderları** ile yeniden görüntüle. Birden fazla proje için **Yerel projeler → Yedeği indir** seçeneğini kullan.

**EN** · Open the published site from the repository homepage. Use **Oda çiz** to draw a floor plan or open **Proje → Yerel projeler → Yeni boş oda** for a blank room. Choose furniture from the catalogue, select the piece and edit its material and LED settings. **3B görünüm → PNG indir** saves a 1920 × 1080 PNG. Open **Proje → Proje renderları** to see it again. **Yerel projeler → Yedeği indir** backs up the workspace.

<a id="windows"></a>
## Windows

**TR** · GitHub deposunun **Releases** bölümünden `MyHome-Windows-x64-0.2.0.zip` indir. Tamamını çıkar, **MyHome.cmd** dosyasına çift tıkla. Uygulama 5188 portunda açılır. **4K Cycles** için [Blender 4.5 LTS](https://www.blender.org/download/lts/4-5/) yükle. Paket içindeki `BASLANGIC.md` farklı kurulum yollarını açıklar. Sahneni aç, kamerayı seç ve **4K render al** düğmesini kullan. Galerideki PNG ve projeyi aynı yedekte saklayabilirsin.

**EN** · Download the Windows ZIP from the repository’s **Releases** section, extract everything and double-click **MyHome.cmd**. The app opens at port 5188. For Cycles install Blender 4.5 LTS, or set the `blender` path in `ayarlar.json` and restart MyHome. The default device is CPU. Open your exported project, select the camera, and click **4K render al**. Open the gallery to view or download the result.

MyHome’u Windows’ta aç

MyHome GitHub deposunun Releases bölümünden MyHome-Windows-x64 ZIP dosyasını indir. Tamamını bir klasöre çıkar ve MyHome.cmd dosyasını çalıştır.

Web’den indirdiğin dosyayı Proje → Projeyi aç ile yükle. Fotogerçekçi render için Blender 4.5 LTS kur.

Windows quick start

Download the Windows x64 ZIP from the project's GitHub Releases page. Extract it and run MyHome.cmd. Use Proje → Projeyi aç to open a project saved in the web app. Install Blender 4.5 LTS for Cycles.
